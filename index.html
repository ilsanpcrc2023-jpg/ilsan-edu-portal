부서 소개

각 부서를 선택하면 소개와 주요 사업, 교육 프로그램을 확인할 수 있습니다

기능제안 & 관리자 가이드

포털 개선 아이디어 및 관리자 운영 매뉴얼

📖 관리자 운영 가이드
8개 부서 담당자가 각자 교육을 등록·관리할 수 있습니다.
1
관리자 로그인
오른쪽 상단 ⚙ 관리 버튼 클릭 → 비밀번호 입력
💡 각 부서 담당자가 동일한 비밀번호로 로그인합니다
2
교육 추가 (각 부서 담당자)
관리자 패널 → 교육관리 → + 교육 추가 클릭
① 본인 부서 선택 (주관부서)
② 교육명·대상·일시·장소·정원 입력
③ 회차가 여러 번이면 시리즈 설정
④ 저장 → 즉시 포털에 반영
3
신청 마감 / 수정 / 삭제
• 마감: 교육 수정 → "신청 상태"를 마감으로 변경 → 사용자에게 "마감" 표시
• 수정: 교육관리 목록에서 ✏ 아이콘 클릭 → 내용 변경 → 저장
• 삭제: 🗑 아이콘 클릭 → 확인 후 삭제
• 비공개: "게시" 체크 해제 → 일시적으로 숨김
4
대시보드 & 성과 확인
📊 대시보드 탭에서 확인 가능:
• QI 성과 지표 (전체 210건 → 실제 185건, 통합교육 23건 / 적용률 10.95%)
• 부서별 공동교육 참여 현황
• 신청 건수·방문자 수 통계
• 부서별·대상별 차트
5
데이터 백업 & 공동교육 관리
• 대시보드 → CSV 다운로드: 신청자 데이터를 엑셀로 백업
• 관리자 패널 → 공동 개최: 다른 부서와 합동 교육 등록
• 관리자 패널 → 게시물 생성: 교육 홍보 카드뉴스 자동 생성
6
부서별 역할 분담
각 부서 담당자의 역할:
• 본인 부서 교육 등록 및 내용 업데이트
• 교육 완료 후 마감 처리
• 신청자 확인 (대시보드에서 CSV 다운로드)

포털 총괄 관리자 역할 (일차의료개발센터):
• 포털 전체 유지보수 및 기능 관리
• QI 성과 모니터링
• 공동교육 조율 및 부서 간 협업 촉진
⚠️ 유지보수 안내:
• 교육 데이터 변경은 관리자 모드에서만 가능합니다
• 포털 디자인·기능 변경이 필요하면 GitHub 저장소에서 코드를 수정합니다
• 신청 데이터는 접수 즉시 담당자 이메일로 발송됩니다(개인정보는 서버에 저장하지 않음)
• 정확한 방문자 통계는 Google Analytics 연동 시 가능합니다
• 모바일(핸드폰)에서도 접속·신청이 가능하도록 반응형으로 구성되어 있습니다
